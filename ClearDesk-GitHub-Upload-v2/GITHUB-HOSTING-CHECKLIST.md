# GitHub hosting checklist

1. Create a new GitHub repository named `cleardesk-website`.
2. Upload every file and folder inside this website folder. Upload the contents, not the outer folder itself.
3. In the repository, open **Settings**.
4. Open **Pages** in the left-hand menu.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder, then click **Save**.
7. Wait for GitHub to show the published address. It can take a few minutes.
8. To use `cleardesk.co.nz`, open **Settings → Pages → Custom domain**, enter `cleardesk.co.nz`, and follow the DNS instructions shown by GitHub.
9. Open the site on your mobile phone and test the menu, the BOTIM buttons and the floating Open BOTIM button.
