# GitHub hosting checklist

1. Use your GitHub repository named `cleardesk-site`.
2. Upload every file and folder inside this website folder. Upload the contents, not the outer folder itself.
3. In the repository, open **Settings**.
4. Open **Pages** in the left-hand menu.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder, then click **Save**.
7. Wait for GitHub to show the published address. It can take a few minutes.
8. First test at `https://erandaks42194219.github.io/cleardesk-site/`.
9. When the test is approved, open **Settings → Pages → Custom domain**, enter `cleardesk.co.nz`, and follow the DNS instructions shown by GitHub. GitHub creates the active `CNAME` file for you.
10. Open the site on your mobile phone and test the menu, BOTIM, WhatsApp and normal phone-call actions.
